## Формат программы

Формат команды:

```text
q,a,v,q'
```

где:

- `q` — текущее состояние;
- `a` — знак, который виден на ленте;
- `v` — знак, который записывается на ленту, или команда движения;
- `q'` — состояние, в которое переходит машина.

Начальное состояние должно иметь имя `0`.

Поддерживаются именованные состояния. Имена состояний, состоящие только из цифр, рассматриваются как числа, поэтому состояния `01` и `1` считаются одним состоянием.
### Команды

В качестве `v` могут использоваться следующие команды:

```text
>   движение головки вправо;
<   движение головки влево;
=   отсутствие движения на данном такте;
#   полная остановка машины.
```

Любой другой знак записывается в текущую ячейку ленты.

Пробел обозначает пустой знак и используется для стирания содержимого ячейки.

Несколько команд можно записывать в одной строке, разделяя их одним или несколькими пробелами.
### Комментарии

Поддерживаются комментарии в стиле C (`//`) и shell (`#`).

Комментарий может занимать всю строку или находиться после команды. Между предыдущей командой и комментарием должен находиться хотя бы один пробел или перенос строки.

Например:

```text
0,0,>,0  // двигаемся вправо
0,1,>,0
0, ,<,1  # нашли конец слова
```
## Пример

Программа выполняет замену `0` на `1` и `1` на `0` в слове:

```text
00, ,<,rep
rep,0,1,mov  rep,1,0,mov  rep, ,>,fin  # переписываем текущую ячейку
mov,0,<,rep  mov,1,<,rep                # двигаемся на шаг влево
fin,0,>,fin  fin,1,>,fin  fin, ,#,fin   # в конце перемещаемся в конец слова
```

## Работа с эмулятором

Во время выполнения программы текущая команда подсвечивается в редакторе. При возврате к правке выполнение сбрасывается, а лента восстанавливается в исходное состояние.

Основные команды управления:

- **Старт** — разобрать программу и перейти в режим выполнения;
- **Шаг** — выполнить один следующий такт;
- **Быстро** — запустить автоматическое выполнение;
- **Моментально** — выполнить программу до остановки без задержки между тактами;
- **Вернуться к правке** — вернуться к редактированию программы и ленты, сбросив выполнение и восстановив исходное состояние ленты;
- **Открыть** — загрузить программу из файла;
- **Сохранить** — сохранить текущую программу в файл;

## Горячие клавиши

В режиме редактирования:

- `Ctrl+Enter` — запустить программу на выполнение;
- `Enter` — запустить программу, если фокус находится на ленте.

В режиме выполнения:

- `Enter` или `Ctrl+Enter` — включить или выключить быстрый режим;
- `Пробел` — выполнить один такт и выйти из быстрого режима;
- `Esc` — вернуться к редактированию программы и ленты.
